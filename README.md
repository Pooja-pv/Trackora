# Trackora

A smarter way to manage your job search.

Trackora is a full-stack job application tracking platform designed to help job seekers organize applications, manage follow-ups, prepare for interviews, and understand their job-search progress.

## Project Goals

- Organize job applications in one place.
- Track application statuses and progress.
- Manage interview dates and follow-up reminders.
- Analyze job-search activity through meaningful statistics.
- Compare job requirements with personal skills.
- Build a secure, tested, and maintainable web application.

## Planned Technology Stack

- Python
- Django
- Django REST Framework
- React
- TypeScript
- PostgreSQL
- pytest
- Vitest
- React Testing Library
- Playwright
- GitHub Actions

## Development Status

Trackora is currently in development. Features will be documented as they are implemented and tested.
